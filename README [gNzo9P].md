# ZCode

**ZCode** — язык программирования с русскими командами. Пишите игры в 2D и 3D прямо в браузере: ничего не нужно устанавливать.

```
пусть х = 0
каждый кадр {
  фон("#10151f")
  если нажата("вправо") {
    х = х + 3
  }
  круг(х, 160, 20, "оранжевый")
}
```

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | сайт языка с примерами и справкой |
| `playground.html` | редактор: подсветка кода, запуск, экран игры, вывод |
| `player.html` | открывалка файлов `.zc`: выберите или перетащите файл, и программа запустится без редактора |
| `flappy-bird.zc` | пример: игра Flappy Bird на ZCode (вставьте код в редактор) |
| `LICENSE` | лицензия MIT |

Интерпретатор — это один HTML-файл. Программа на ZCode превращается в JavaScript и запускается в браузере.

## Быстрый старт

1. Откройте `playground.html` в браузере (или страницу на GitHub Pages).
2. Выберите пример или напишите свою программу.
3. Нажмите «Запустить». Горячие клавиши: `Ctrl+Enter` или `Cmd+Enter` в редакторе.

Управление в играх: стрелки, пробел, `w a s d`. На телефоне есть кнопки под экраном игры.

## Для начинающих

- **Уроки.** Кнопка «Уроки» в редакторе (или ссылка `playground.html#lessons`) открывает 8 коротких заданий с автоматической проверкой: от первой команды до игры.
- **Ошибки с номером строки.** Например: `Ошибка в строке 3: неизвестное имя «нет»`. Незакрытые скобки и кавычки тоже подсвечиваются номером строки.
- **Удобный редактор.** `Tab` ставит отступ, `Enter` сохраняет отступ и добавляет его после `{`. Чтобы вернуть `Tab` для перехода по странице, нажмите `Esc`, а затем `Tab`.
- **Проекты.** Раздел «Мои проекты»: введите название, нажмите «Сохранить», и программа появится в списке с кнопками «Открыть» и «Удалить» (удаление в два нажатия). Одноимённый проект обновляется. Проекты и последний черновик хранятся в браузере на этом устройстве (localStorage): при перезагрузке страницы код возвращается, но в другом браузере или после очистки данных сайта проекты не появятся.
- **Ввод от пользователя.** `спросить("Как тебя зовут?")` показывает окно запроса. Если окно не появляется (например, браузер его блокирует), впишите ответы в поле «Ответы для «спросить»» под выводом, по одному в строке.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий (**Add file → Upload files**).
2. Откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`.
3. Через минуту-две сайт откроется по адресу `https://ваш-ник.github.io/название-репозитория/`.

Для 3D страница подгружает библиотеку three.js (r128) с cdnjs, а шрифты — с Google Fonts, поэтому нужен интернет.

## Справка по языку

| Команда | Что делает |
| --- | --- |
| `пусть х = 5` | создаёт переменную (`константа` — неизменяемую) |
| `скажи х` | выводит значение |
| `спросить("вопрос")` | спрашивает у пользователя и возвращает ответ (текст; для числа используйте `число(…)`) |
| `если … { } иначе { }` | условие, есть и `иначе если` |
| `пока … { }` | цикл, пока условие верно |
| `повтори 3 раза { }` | повторяет блок |
| `для к от 1 до 5 { }` | цикл со счётчиком |
| `для каждого с в список { }` | обход списка |
| `функция имя(а, б) { }` | функция, результат — `вернуть` |
| `прервать`, `продолжить` | управление циклом |
| `и`, `или`, `не` | логика; значения `истина`, `ложь`, `ничего` |
| `# текст` | комментарий |

Блок можно записать в одну строку: `если х > 1 { скажи "да" }`. Вложенные блоки в одной строке и несколько команд через `;` не поддерживаются, пишите их построчно. В условиях одиночное `=` читается как сравнение.

### Игры

| Команда | Что делает |
| --- | --- |
| `каждый кадр { }` | игровой цикл, около 60 раз в секунду |
| `нажата("влево")` | проверка клавиши: `влево`, `вправо`, `вверх`, `вниз`, `пробел`, `ввод`, `w`, `a`, `s`, `d` |
| `мышь()` | объект с полями `x`, `y`, `нажата` |
| `фон`, `прямоугольник`, `круг`, `линия`, `надпись` | рисование в 2D (холст 480×320) |
| `начать3д`, `камера`, `куб`, `коробка`, `сфера` | 3D-сцена; у фигур есть `x`, `y`, `z`, `поворот_x`, `поворот_y`, `поворот_z` |
| `звук(440, 0.2)` | простой звук: частота и длительность |
| `время()` | секунды с запуска |

Цвета: `красный`, `зелёный`, `синий`, `жёлтый`, `белый`, `чёрный`, `оранжевый`, `фиолетовый`, `серый`, `розовый` или любой код вроде `#10151f`.

Встроенные функции: `длина`, `случайное`, `корень`, `округлить`, `текст`, `число`, `макс`, `мин`, `синус`, `косинус`, `пол`, `абс`, `добавить`, `удалить_первый`, `убрать_последний`.
