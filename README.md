# ZCode

**ZCode** — лёгкий веб-редактор для создания и настройки 2D- и 3D-сцен. Проект работает в браузере, сохраняет сцены в формате `.zc` и не требует установки дополнительных программ.

## Возможности

- Создание и редактирование 2D- и 3D-сцен
- Работа с объектами сцены: положение, масштаб и другие параметры
- Настройка цвета объектов в формате HEX
- Переключение между 2D- и 3D-режимами
- Управление 3D-камерой с клавиатуры: `W`, `A`, `S`, `D`
- Сохранение и загрузка проектов в формате `.zc`
- Настройка заголовка проекта (`TITLE`)
- Работа непосредственно в браузере

## Запуск

1. Скачайте или склонируйте репозиторий.
2. Откройте файл `zeditor.html` в любом современном браузере.

## Формат проекта

Проекты ZCode сохраняются в файлах с расширением `.zc`.

В файле могут храниться параметры сцены, объектов, их координат, масштаба, цвета и названия проекта. Используйте сохранение, чтобы продолжить работу над сценой позже или поделиться ею с другим пользователем.

## Управление

| Действие | Управление |
|---|---|
| Перемещение камеры в 3D | `W`, `A`, `S`, `D` |
| Выбор объекта | Клик по объекту |
| Изменение позиции | Поля `X`, `Y`, `Z` |
| Изменение масштаба | Поле масштаба |
| Изменение цвета | HEX-значение или выбор цвета |
| Сохранение проекта | Кнопка сохранения в интерфейсе |
| Загрузка проекта | Открытие файла `.zc` |

## Панель свойств

Для выбранного объекта доступны основные параметры:

- **Позиция** — координаты `X`, `Y` для 2D и `X`, `Y`, `Z` для 3D
- **Масштаб** — изменение размера объекта
- **Цвет** — настройка через HEX-код
- **Название проекта** — параметр `TITLE`
